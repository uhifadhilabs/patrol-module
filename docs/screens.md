# Screens

| Screen | Route |
|---|---|
| Widget dashboard | `patrol_dashboard` |
| Widget library (edit surface) | `patrol_widgets` |
| Patrol detail | `patrol_show` |
| Observation detail | `patrol_observation_show` |
